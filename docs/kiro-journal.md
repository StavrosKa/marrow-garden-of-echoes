## 2026-11-16 - marrow-input task 2: frame types, landmark validity and geometry

- Kiro feature used: spec, task 2 of `marrow-input` (model: Claude Opus 5.5)
- What was built:
  - Task 1 was reviewed, approved and committed as c13d2ab "Add tuning module and validation". This entry records that; the task 1 entry is unchanged.

A landmark is valid if and only if visibility >= `tuning.minVisibility` and 0 <= x <= 1 and 0 <= y <= 1. Every comparison with NaN is false, so NaN is invalid without a separate check.
  - `packages/marrow/src/core/geometry.ts`, internal and not on the barrel: `dist`, `clamp`, `add`, `sub`, `scale` and `lerp`, on the `Vec2` imported from `frame.ts`. `lerp` is a + (b - a) * t, the form of the smoothing step in Req 9.4. `dist` takes the square root of the sum of squares, so exact inputs such as 3-4-5 give exact results.
  - `marrow/core` now also exports `Vec2`, `WristId`, `Landmark`, `PoseLandmarks`, `PoseFrame`, `LANDMARK_INDEX` and `isLandmarkValid`.
